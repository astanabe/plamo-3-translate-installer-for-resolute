# plamo-3-translate-installer-for-resolute

PLaMo 3 Translate installer script for Ubuntu Server 26.04 Resolute Raccoon

# Usage

```
bash install-plamo-3-translate.sh                    # interactive install
bash install-plamo-3-translate.sh --accept-license \
    --destdir /opt/plamo-3-translate --model 2b ...  # non-interactive install
bash install-plamo-3-translate.sh --uninstall        # uninstall
```

- Every prompt has a corresponding command-line option (and environment variable). When all required values are given, the installer runs without prompting.
- Re-running the installer updates the existing installation in place (files and systemd units are overwritten; an already-downloaded GGUF file is reused).
- `--uninstall` stops and disables the services and removes the systemd units, the nginx site configuration and destdir.

# Engine

- llama.cpp b12366
  - https://github.com/ggml-org/llama.cpp/releases/tag/b12366
- Prebuilt binary chosen by the user from:
  - CPU (`llama-b12366-bin-ubuntu-x64`)
  - Vulkan (`llama-b12366-bin-ubuntu-vulkan-x64`)
  - CUDA 12.8 / 13.5 (`llama-b12366-bin-ubuntu-cuda-*-x64`)
  - ROCm (`llama-b12366-bin-ubuntu-rocm-10.0-x64`)
- The installer detects available GPUs and suggests a default backend.
- llama-server options: `-c 16384 --jinja --no-prefill-assistant --alias plamo-3-translate` (context size is configurable)

# Quantization

- Q2_K
- Q3_K_M
- Q4_K_M (default)
- Q4_0 (0.8B and 2B models only)

# Architecture

- Web server (TCP 18080 by default) (nginx-full)
  - uWSGI (`uwsgi`, `uwsgi-plugin-python3` from apt)
    - plamo-3-translate-server.py (provided in this repository)
      - `GET /` : translation form (HTML)
      - `POST /api/translate` : JSON API
      - llama-server (TCP 28080 by default)

- plamo-3-translate-server.py and plamo-3-translate-client.py use the Python standard library only.
- All services run as the user specified at install time (default: `plamo`). If the user does not exist, it is created as a system user without login.
- llama-server listens on `127.0.0.1` by default. If exposure is enabled, it listens on `0.0.0.0` with an API key (`--api-key`) generated by the installer.
- TLS and authentication for the web server are out of scope.

# Client

- Web browser
- plamo-3-translate-client.py (provided in this repository)

# Procedure

1. Ask user for destdir (default `/opt/plamo-3-translate`), username (default `plamo`), model (default 2B), quantization (default Q4_K_M), llama.cpp backend, context size (default 16384), web server port (default 18080), llama-server port (default 28080), whether to expose the llama-server, and license acceptance
2. Check prerequisites: ports are not in use, enough free disk space and memory for the selected GGUF file (warn and ask to continue if insufficient)
3. Install dependencies via apt
4. Create the service user if needed
5. Download and install llama.cpp and GGUF file
6. Generate and install systemd unit files and nginx site configuration, and start and enable servers (if ufw is active, ask whether to open the ports)
7. Test llama-server (`/health`) and translate a short sentence through the web server, checking that a non-empty result is returned
